# Dataset

This project uses **Online Retail II** from the UCI Machine Learning Repository.

The dataset is intentionally not included in this repository. Obtain it from the dataset's official UCI page, then place the CSV in your Databricks Volume or update the ingestion notebook to the location used in your workspace.

Notebook 01 currently expects:

`/Volumes/workspace/ecommerce/raw_data/online_retail_II.csv`

The data is governed by its source terms. Refer to UCI for dataset citation and terms.
